# 👾 Space Invader Game (Python)

A simple **Space Invader game** built using Python. This project demonstrates basic game development concepts like player movement, enemy spawning, collision detection, and scoring.

---

## 🎮 Features

- Player spaceship movement (left & right)
- Multiple enemies
- Bullet firing system
- Collision detection
- Score tracking
- Game over condition

---

## 🛠️ Tech Stack

- **Language:** Python
- **Library:** Pygame (or mention your library if different)
